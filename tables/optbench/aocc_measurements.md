### Время выполнения
```bash
/usr/bin/time -f "real %e\nuser %U\nsys %S" bash -c "for i in {1..1000}; do ./$EXECUTABLE > /dev/null; done"
```

```bash
stat -c %s "./$EXECUTABLE"
```
