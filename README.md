# Сравнение оптимизаций компиляторов GCC, AOCC и ICX

## Описание

Проект посвящен сравнительному анализу оптимизаций компиляторов:
- **GCC** 13.3.0
- **AOCC** (AMD Optimizing C/C++ Compiler) 5.0.0 на базе clang-17
- **ICX** (Intel LLVM-based Compiler) 2026.0.0

## Методология

### Измерения производительности

Замеры выполняются с помощью утилиты `/usr/bin/time`:
```bash
/usr/bin/time -f "real %e\nuser %U\nsys %S" bash -c "for i in {1..1000}; do ./$EXECUTABLE > /dev/null; done"
```

### Измерение размера
```bash
stat -c %s "./$EXECUTABLE"
```

## Анализ оптимизаций

### Основные выводы:

1. **Размер кода**: AOCC с флагом -Os генерирует самый компактный код (12208 байт)
2. **Быстродействие**: GCC показывает наилучшее время выполнения
3. **Векторизация**: ICX использует SSE/AVX инструкции для оптимизации

### Примеры оптимизаций:

- **Развертка циклов** (Loop Unrolling)
- **Встраивание функций** (Function Inlining)
- **Удаление мертвого кода** (Dead Code Elimination)
- **Оптимизация памяти** (Memory Optimization)

##  Структура проекта

- `source/` - исходные тестовые программы (AES, optbench)
- `assembler/` - ассемблерный вывод для каждого компилятора
- `results/` - результаты замеров производительности
- `analysis/` - детальный анализ оптимизаций

## Сборка

```bash
# GCC
gcc -O2 source/program.c -o program_gcc_O2

# AOCC
clang-17 -O2 source/program.c -o program_aocc_O2

# ICX
icx -O2 source/program.c -o program_icx_O2
```
